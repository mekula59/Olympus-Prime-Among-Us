# Worldbuilding UI

Use this skill for targeted UI polish inside the existing Olympus Prime Gamesnight Hub direction.

## Product Direction

- Hub-first product.
- Discord-first, site-second framing.
- The Hub is memory, identity, archive, and story.
- Games are worlds users enter from the launcher.
- Among Us is a flagship game module.
- Leap of Legends is also a flagship Olympus Prime game.

## UI Rules

- Preserve the current route map and shell.
- Do not add features during polish passes.
- Keep the Hub calm, premium, and readable.
- Let game modules carry more warmth and personality.
- Stay mobile-first with strong touch targets.
- Avoid dashboard, console, generic landing-page, or decorative clutter.

## Workflow

1. Identify the exact screen or component being improved.
2. State the primary visual/interaction weakness before editing.
3. Make the smallest focused UI change.
4. Verify with `npm run typecheck` and `npm run build` when code changes.
5. Preview the affected route when practical.
